# DeepSeek Harness 视频双盲评分表

请先分别观看 `sample-amber.mp4` 和 `sample-cobalt.mp4`，不要查看原项目目录或文件元数据。

每项按 1–5 分评分：

| 维度 | Amber | Cobalt |
| --- |------:|-------:|
| 信息准确、可信       |   3.5 |    3.5 |
| 内容结构清晰 |     3 |    3.5 |
| 视觉表达有效 |     3 |    3.2 |
| 节奏与信息密度 |     3 |      4 |
| 字幕/旁白体验 |     3 |      4 |
| 整体完成度 |   3.1 |    3.3 |

详细体验：
Cobalt：
优点：视觉创意优异，信息密度高、表达有重点、有节奏、
缺点：效果不稳定，导致能看到优秀的设计，但视觉效果不好，体现在多个转场中出现闪动帧、元素模块空间规划有失误，表现为视图上模块卡片堆叠（如0:44，0:59），如果想要体现出展开局部细节的话，可以考虑通过遮罩弱化作为背景的全局效果，高亮局部的模块；

Amber： 
优点：效果稳定很多，除1:45前后的视图出现了一处疑似元素堆叠（箭头、圆圈、线条重叠且意图不清晰）的表达外，质量稳定，左右结构是舒适区，使用动画相对比较克制
缺点：样式过于模板化、信息密度低；欠缺字幕/旁白的补充能力
