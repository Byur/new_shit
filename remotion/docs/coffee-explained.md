## 1. 学习承诺（这份片子到底要教会什么）

**一句话论点：一袋咖啡的正面写着产地，背面写着决策；杯子里装的是背面。**

观众原有的心智模型是「产地决定风味」——耶加雪菲就是花香，苏门答腊就是泥土味，好像风土是一种无法解释的地方神秘主义。这个模型能做出一件事：认出标签。它做不到另一件事：**预测一杯没喝过的咖啡**。

片子结束时，观众应该能拿起一袋没见过的豆子，只看背面的四行字，就对杯子里的味道做出有根据的推断。这是本片全部证据的验收标准。

### 四行字构成的因果链

| 决策 | 机制 | 可观测后果 |
|---|---|---|
| **物种** | 罗布斯塔咖啡因约为阿拉比卡两倍、绿原酸更高、蔗糖更低 | 更苦更涩、橡胶与泥土味；同时抗虫抗病耐热，所以更便宜、占比在涨 |
| **品种** | 全部阿拉比卡来自几百年前被带出非洲的极少数个体；1970 年代叶锈病逼出带罗布斯塔血缘的抗病杂交种 | 品种决定风味上限；抗病分支普遍杯测偏低 |
| **海拔** | 咖啡只在乎温度，气温每升高 1000 m 降约 6.5 ℃，所以海拔可以替代纬度 | 埃塞俄比亚要 2000 m，巴西 1100 m，越南 600 m |
| **处理法** | 同一棵树同一天的果子，发酵方式不同 | 酸度、甜度、醇厚度、缺陷风险各走一条路 |

四行字**任意一行**都能单独改变杯子的结果，而且它们的顺序是因果顺序而不是清单顺序：物种决定基因上限 → 品种在这个上限内移动 → 海拔决定这个品种能不能兑现 → 处理法在果实离开树之后再加一个维度。

### 明确排除在范围之外的

- 烘焙曲线、拼配配方、冲煮参数（水温水粉比）：属于「杯子之后」，与本片「豆子之前」的边界冲突。
- 咖啡史与殖民贸易史：有趣，但不参与四行字的推断链。
- 「XX 庄园 XX 批次」级别的单一庄园叙事：会让片子退化成品鉴笔记。

## 3. 视觉语言

### 3.1 形式主张

**用一张真正的等距圆柱投影世界地图作为唯一连续画布，让「纬度」在屏幕上就是一条水平线。**

选这个投影不是为了好看，是因为片子的第三幕要讲「海拔替代纬度」。在等距圆柱投影里，回归线是水平直线，咖啡带是一个真正水平的带子，埃塞俄比亚和巴西的相对位置可以直接目测。换成任何花哨的投影，这条论证就得靠嘴说。

地图数据来自 Natural Earth 1:110m（公有领域），经由 `world-atlas` 的 TopoJSON 分发下载，由 `scripts/build-geo.mjs` 解码、投影、抽稀成 `src/coffee/geo.ts` 里的静态 SVG path。

### 3.2 连续画布

地图**从不卸载**。七幕全部画在同一张画布上，只是改变强调程度：

- 相机是一条纯函数 `viewAt(frame)`，关键帧锚定在旁白行上，经纬度线性插值、缩放取对数插值。
- 国家高亮 `highlightsAt(frame)`、产地标记 `markersAt(frame)`、地图不透明度 `mapOpacityAt(frame)` 同样是纯函数。

这直接解决上一期的一个真实缺陷：分幕边界会出现整帧空白。本期六个分幕边界的前后各两帧，相邻帧平均亮度差全部 ≤ 1.2（见 §5），**没有任何一帧是空的**。

### 3.3 色彩语义

| 颜色 | 含义 |
|---|---|
| `#E3A34A` 金 | 阿拉比卡 |
| `#C25B3E` 陶土 | 罗布斯塔，以及一切「抗病分支的代价」 |
| `#7FB2A8` 灰绿 | 海拔与温度 |
| `#A8C46B` 草绿 | 野生/地方种与非洲阵营 |
| `#C98BB0` 藕紫 | 选育品种（铁皮卡/波旁及其后代） |
| `#6FA8DC` 蓝 | 水洗 |
| `#E0B84B` 黄 | 日晒 |
| `#D98E4A` 橙 | 蜜处理 |

| `#D9C27A` 米金 | 价格与拍卖 |

与上一期的红涨绿跌完全无关，是重新按「物理产物」而非「交易屏幕」推导出来的。

### 3.4 贯穿全片的器件：页眉的四格决策链

页眉右侧从第一帧起就显示 `物种 / 品种 / 海拔 / 处理法` 四个格，全部锁定。每一幕开始时解锁一格并填入结论。到第六幕三大阵营出现时，观众看到的是一个已经被填满的推理模板——产区卡片上的四行和页眉上的四格是同一套东西。

## 4. 技术说明

### 4.1 音频管线

沿用「先量真实时长、再吸附到整帧」的做法，但构建脚本已经参数化（`--project coffee`），不再写死路径：

- 每一行独立用 `say` 合成 WAV，量出真实采样数。
- 22050 / 30 = **735 采样/帧**，整除，所以每一行都能精确吸附到整帧边界。
- 逐行拼接成 `public/coffee-narration.wav`，同时写出 `src/coffee/narration.timing.json`。
- 与上一期共享 SHA1 缓存（`.cache/narration/`），按「语音+语速+文本」做键。

动画代码不写绝对帧号，只写 `L('geography', 8)` 这样的行引用。改一句旁白，整条时间线和画面一起重排。

实测：460.40 s、22050 Hz 单声道、峰值 −2.35 dBFS、460 个 1 秒窗口里 459 个有声。

### 4.2 地图与相机

`scripts/build-geo.mjs` 把 TopoJSON 的差分编码弧段解码回经纬度环形，投影到 2000 × 600 的「世界空间」（经度 −130…170，纬度 ±45；砍掉空荡的太平洋让宽高比可用），抽稀到 0.45 世界单位以下合并，输出静态 path 字符串（230 KB）。

相机用「中心点 + 经度跨度」表示；纬度跨度由画布宽高比和世界宽高比反推，所以任何缩放级别下投影都保持等距圆柱。

### 4.3 取景细节

`AltitudeStrip` 把每个产区放在同一条 0–2400 m 的轴上比较。这是第三幕和第六幕共用的器件：埃塞俄比亚的 1900–2200 和越南的 600–800 直接并排，观众不需要记住数字。

## 5. 质量验证

### 5.1 方法

**本会话没有可用的视觉模型**（`read_image` 对全部已配置模型都返回 `does not declare image input`）。因此全部画面验证都是**程序化像素分析**，不是肉眼审阅。这一点必须明确：像素分析能证明布局越界、整帧空白、元素缺失、区域覆盖；它**不能**证明排版美观、字号在观看距离下舒适、颜色搭配好看。这些仍然需要人眼确认。

`scripts/qa-frames.mjs` 一次性打包、`selectComposition`、逐帧渲染 still，再用 `scripts/lib/png.mjs`（零依赖 PNG 解码）分析：

- `safe` 安全框 `x∈[0,1844], y∈[0,1064]`：任何墨迹越界都报出来并给出越界包围盒。
- 分幕边界前后各两帧的 `frameDelta`，用于发现整帧空白。
- 具名区域的 `regionInk`，用于确认某块面板真的画出来了。

### 5.2 首轮全片扫描（47 帧，覆盖七幕与全部分幕边界）

结果：**安全框越界 0 处**（越界项只有左侧 6 px 的进度条，属设计元素；末两帧越界是进度条点亮部分超出了我保守设定的 y=1064，实际画布高 1080）。

发现并修复的真实缺陷：

| # | 现象 | 原因 | 修复 |
|---|---|---|---|
| 1 | 地图看起来是一整块陆地 | 陆地填充 `#2A2119` 亮度 34.3，只比海洋高不到 1 级 | 加海洋底色，陆地提到 `#4E3E2C`；分层后陆地/海洋亮度 64 / 15 |
| 2 | 第 9560 帧右侧有 47 px 溢出 | 「厌氧发酵」说明文字过长，从 x=1178 一直排到 x=1913 | 缩短文案，右端收进条内 |
| 3 | 第三幕海拔说明文字越过内容右边界 8 px | 注记以 `axisX+axisW+96+8` 为锚点 | 轴宽预留 300 px，注记右对齐到 `x+width-8` |
| 4 | 第二幕「遗传瓶颈」两行说明压在「埃塞俄比亚野生种群」节点上 | 说明写在 `ROW[1]+62/+90`，而节点就在 `ROW[2]` | 上移到 `ROW[0]+86/+116`，与节点拉开 44 px |
| 5 | 第三幕链式说明面板与霜冻提示框横向重叠 30 px | 霜冻框以 `frostPt.x-250` 起，链式面板右边界在 836 | 霜冻框改为 `frostPt.x-200`，两者间隔 14 px |
| 6 | 末幕大字与上一行字幕有四帧重叠 | 大字提前 4 帧进场 | 大字改为与最后一行字幕同帧进场 |

以上六项修复后重跑 10 帧定向扫描（含全部受影响帧）：安全框越界仍为 0，只剩下左侧 6 px 进度条这一项设计元素。

### 5.4 内容校验

#### 产量数字

画面上出现的比例来自 FAO 2023 年绿咖啡产量序列（世界 11.06 Mt = 184.4 百万袋）。绝对袋数只用于地图标记的尺寸，屏幕上印的是**占比**——FAO 与 USDA 的绝对袋数分歧很大（巴西 56.8 vs 66.4 百万袋），占比跨源稳定得多。物种占比沿用 ICO 口径。

#### 逐条事实核查

初稿写完后做了一轮独立核查：14 项断言逐条对照一手来源，SCA 与 Cenicafé 的部分直接读 PDF 原文。结果是 **5 项成立、6 项部分有误、3 项连前提都要改**。三处必须改的：

| 原稿 | 问题 | 改后 |
|---|---|---|
| 「越南更靠北，600 米也行」（承接的是阿拉比卡） | **错**。600 m 是 Đắk Lắk 的**罗布斯塔**平台；越南 97% 是罗布斯塔，它的阿拉比卡种在 1500 m 的大叻 | 「越南更靠北，但 600 米只够种罗布斯塔」 |
| 「咖啡因和绿原酸是化学武器，含量越高虫不吃、病不上身」 | **因果错**。咖啡因确实是杀虫剂，但抗锈病是基因对基因的抗性，来自帝汶杂交导入的 canephora 片段，不是生物碱的效果。反例：咖啡果小蠹专吃咖啡因含量最高的组织 | 拆成两句：这两个分子只解释拒食；抗病是另一套基因组的能力，「罗布斯塔碰巧两样都占」 |
| 「1994 和 2021 年巴西两次霜冻，价格直接翻倍」 | **2021 不成立**。1994 年 IMF 年均价 71 → 147 ¢/lb，确实翻倍；2021 年是 151 → 205 → 255 ¢/lb，+36% 再 +69%，年均约 1.7 倍 | 只有 1994 年说成翻倍，2021 年说成大幅跳涨 |

另有几处按核查结果收紧：

- **成分改成区间**。四个化合物的文献点值互相差到两倍以上，画一根柱子就是在宣称不存在的精度。改成区间条后，咖啡因干净分离（约两倍），而**蔗糖的区间是真的重叠**，图上也照实叠着——这比一根整齐的柱子更诚实。
- **删掉耗水数字**。广泛流传的「水洗 20–40 L/kg」按 Cenicafé 原文是**每公斤干羊皮豆**而不是生豆，而且那个区间没有一手来源支持。现在只留定性描述，加一条有出处的对比：传统水洗 ≈ 39 L/kg 干羊皮豆，机械去胶机可降到 ≈ 0.6 L——**差别在设备，不在产地**。
- **湿刨法含水改为 40–45%**（一手测量值），并删掉「豆体呈深绿色」——那篇测量说的是偏白，两个来源冲突，索性不提颜色。
- **不再暗示处理法有普适排名**。对照试验里日晒在秘鲁排第一、在哥伦比亚排第五，所以在风味矩阵上方标了「典型描述，非普适排名」。
- **补上 SCA 2024 改版**。80 分线属于旧协议；2024 年起 SCA 已改用 Coffee Value Assessment，画面下方加了小字说明。

#### 几处刻意保留的模糊

- 海拔区间是各国公布或研究中出现的**商业化典型区间**，不是植物学极限。核查明确指出巴西 800–1200 m 找不到出处（已改为 950–1150 m）、肯尼亚查不到数字区间（已收窄到常引的 1400–2000 m）。
- 6.5 °C/km 是 ISA 标准大气递减率；在饱和湿润的热带山地，实际更接近湿绝热（约 5–6 °C/km）。片子用它是因为它是观众能查到的那个数字——方向没错，量级偏大。
- 蜜处理、日晒、湿刨的耗水量**没有任何一手数字**，所以一个都没写。

标注了来源：页眉徽标写明 `数据来源 · FAO 2023 · ICO · SCA`。

## 6. 诚实声明

- **画面从未被人眼看过**（也没有被任何视觉模型看过）。全部结论来自像素统计，覆盖布局越界、空白帧、区域存在性与时长同步；不覆盖美观判断。§5.4 能证明的是文字与数字有出处，它证明不了这些东西摆在屏幕上是好看的。
- 事实核查是在初稿之后才做的，所以旁白重建过一次、时间线整体后移；最终渲染对应的是核查之后的版本。
- 旁白文本与音频时长是一手实测的（WAV 采样数），不是估算。
- 产地海拔区间用的是各国官方/WCR 公布的**商业化典型区间**，不是植物学极限。
- 处理法的耗水量是常见引用区间，不同来源差异较大（全水洗有报到 80–150 L/kg 的口径），屏幕上给的是保守区间。
- 霜冻对价格的影响说「翻倍」是针对国际期货价格的量级描述，不是精确倍数。

## 7. 复现

```bash
cd remotion

# 1. 烘焙地图数据（已提交 src/coffee/geo.ts，通常不需要重跑）
node scripts/build-geo.mjs

# 2. 合成旁白并写出时间线
node scripts/build-narration.mjs --project coffee

# 3. 类型与 lint
../node_modules/.bin/tsc
../node_modules/.bin/eslint src

# 4. 像素 QA（无头）
node scripts/qa-frames.mjs --plan scripts/qa-plan.json

# 5. 渲染（无头）
../node_modules/.bin/remotion render CoffeeExplained out/coffee-explained.mp4 \
  --codec=h264 --crf=17 --pixel-format=yuv420p \
  --audio-codec=aac --audio-bitrate=192k --concurrency=6
```
