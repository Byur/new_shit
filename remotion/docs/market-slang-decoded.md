# 股市黑话解码 (MarketSlangDecoded) — 创作与验收说明

一期 6 分 48 秒的中文股市黑话科普视频。Composition id：`MarketSlangDecoded`，
1920×1080 / 30fps / 12311 帧。所有源码在 `src/market-slang/`。

本片与仓库中已有的 `StockSlangExplainer` 是两条独立的创作线，没有复用其素材、结构或脚本。

---

## 1. 教学方向：黑话不是术语，是压缩过的仓位

市面上解释黑话的做法，基本是「词典体」：一个词配一句定义，再配一张示意图。
这样讲完，观众记住的是一堆孤立名词，看完仍然不会用它读盘。

本片换一个组织方式：**黑话压缩的不是知识，而是「谁站在什么位置」**。
所有词都从同一个机制里长出来，因此可以互相解释，而不是彼此并列。

全片只论证四件事，逐层加深：

| # | 命题 | 影片中的落点 |
|---|---|---|
| ① | 一笔交易有四个名字，名字描述的是**你是谁**，不是价格 | 同一个成交价 8.16，卖方叫「割肉」，买方叫「抄底」 |
| ② | 仓位会**机械地改变价格**：10 元附近的密集成本区会变成真实的天花板 | 用真实口径的筹码分布图，展示套牢盘在成本线附近的卖出压力 |
| ③ | 「洗盘」和「出货」描述的是**同一根 K 线**，区别只在于一个无法验证的动机判断 | 拆词：`描述（价格从 12 跌到 8）` + `预测（后面还有更大的上涨）`，后者被伪装成前者 |
| ④ | 「割韭菜」既命名了一个自我复制的结构，也在修辞上**抹掉了拿镰刀的人** | 把「割韭菜」拆开，追问「谁在割？」 |

结尾落到三个可以随身带走的问题，而不是三个术语：
**谁在说话 · 他想让我做什么 · 如果他说错了会怎样**。

## 2. 叙事与节奏

- 7 幕：`hook` → `trade` → `pressure` → `duallabel` → `pairs` → `leek` → `coda`。
- 语速刻意保持 **4.3 字/秒**（`say -v Tingting -r 156`）。这是全片最长的一处克制：
  宁可 6:48，也不把信息密度堆到观众跟不上的程度。改写台词时**不要**提高 rate 来缩短时长。
- 每一幕的每一次视觉变化都挂在具体台词行上（见下节），不靠猜时间点。
- 幕与幕之间保留 18 帧交叉淡出，避免「上一幕整体消失、下一幕还没起来」的空闪。

## 3. 视觉语言

### 一条连续的时间轴

全片只有**一张图**：200 个交易日的模拟 K 线，`TODAY = 136`。
任何时刻变化的只有镜头（pan/zoom）、叠加层和标注。
场景连续性因此是结构上成立的，而不是靠后期对齐维持。

`src/market-slang/camera.ts` 里的每个 key 只有一个 `at` 字段，含义是**镜头抵达该视图的那一帧**，
位移从 `at - MOVE` 开始做 smoothstep 插值。所有 key 都写成 `at('scene', lineIndex)`，
所以改完台词重跑 `npm run narration:build`，全部视觉节拍会自动重新对时。

### 颜色语义

| 颜色 | 含义 |
|---|---|
| `#F0453F` 红 | 上涨 / 浮盈（A 股约定） |
| `#17B978` 绿 | 下跌 / 浮亏 |
| `#93A1B5` 灰蓝 | 可观察的**描述** |
| `#E9B44C` 琥珀 | 某人的**预测** / 无法验证的说法 |

琥珀色是全片唯一的「可疑色」：凡是琥珀色出现的地方，说的都是别人希望你相信的东西。
`Hook` 里黑话被点亮成琥珀，`DualLabel` 里「预测」那一层被滑到「描述」下面，`Coda` 里三个问题
用琥珀收口——同一条视觉规则贯穿到底。

### 数据诚信

K 线、筹码分布、事件日期全部是**确定性生成的模拟数据**（`chart.ts`，锚点样条 + 固定种子噪声）。
画面上始终有标识：`模拟数据 · 非真实行情`（头部）与 `示意图形 · 非真实行情`（Pairs 幕）。
`chart.ts` 里的 `EVENTS` 是数值意义上的真值来源，各幕不得硬编码价格。

## 4. 分幕与计时

| 幕 | 帧区间 | 行数 | 在做的事 |
|---|---|---|---|
| `hook` | 24–1071 | 9 | 一段人人都「读懂」的股评，逐字点亮黑话，再反问「你到底看懂了什么」 |
| `trade` | 1095–3586 | 21 | 你 10 元买入 → 涨到 12.36 → 跌到 8.16 割肉；「他」在同一价位抄底。同一笔成交，两个名字 |
| `pressure` | 3610–5264 | 14 | 10 元密集成本区 → 反弹到成本线就被卖回来 → 筹码分布图证明这不是玄学 |
| `duallabel` | 5288–7283 | 18 | 洗盘 / 出货 两个标签落在同一根 K 线上；拆词暴露「预测伪装成描述」 |
| `pairs` | 7307–8362 | 9 | 三组示意图（洗盘/破位、突破/诱多、蓄势/筑顶）证明这是语言结构而非个例 |
| `leek` | 8386–10605 | 17 | 真实图上的完整周期 → 四格循环条 → 拆开「割韭菜」，追问「谁在割？」 |
| `coda` | 10629–12245 | 13 | 回到开头那句话，三个问题，把责任从词还给说话的人 |

## 5. 技术实现要点

- **旁白**：`narration.script.json` 是唯一真源（101 行）。`scripts/build-narration.mjs`
  逐行调用 `say` 合成，按 SHA1 缓存在 `.cache/narration/`，裁剪/补齐到**整帧**后拼成
  单条 `public/market-slang-narration.wav`（22050Hz 单声道，22050/30 = 735 采样/帧），
  并产出 `narration.timing.json`。整帧对齐意味着音画漂移恒为 0。
- **字幕**：`components/Captions.tsx` 每条台词一条字幕，在下一行开始前 7 帧交叉淡入淡出。
- **镜头**：`components/ChartCanvas.tsx` 通过 `makeProjector(view)` 把 (day, price) 映射到屏幕，
  各幕共用同一个投影器，所以标注天然跟着镜头走。
- **幕间交接**：`MarketSlangVideo.tsx` 在切幕后继续渲染上一幕 18 帧并线性淡出。

## 6. 验收证据

### 自动化帧 QA

`scripts/qa-frames.mjs` 一次性打包，批量渲染静帧并测量：
墨迹覆盖率、构图安全框外的墨迹、命名区域的覆盖率、相邻帧平均亮度差。
`scripts/lib/png.mjs` 是无依赖 PNG 解码器（本环境没有可用的图像识别模型，
所有版面判断都必须是程序化的，不能用眼睛看）。

命令：`npm run qa:frames`（读取 `scripts/qa-plan.json`）。

**最终结果（v4，33 帧，覆盖全部 7 幕与 6 个幕边界）：安全框违规 0/33。**

安全框取 `x∈[18,1836] y∈[30,1046]`——即本片自身的排版网格（左侧价格轴、右侧筹码栏、
顶部头部、底部字幕各自的边距）。

修复过程中被 QA 抓出并修掉的真实缺陷：

| 缺陷 | 症状 | 修法 |
|---|---|---|
| 价格轴刻度步长算错 | 出了 35 个刻度，标签互相重叠并压到 x=20 | `niceStep` 改为取第一个 ≥ raw 的候选值 |
| 「今天」刻度丢失 | 日刻度按 20 步进永远命不中第 136 天 | 先塞入 `TODAY` 再补其余刻度 |
| 刻度标签画出图外 | 镜头拉近后「今天」标签落到 x=1919 | 只绘制落在绘图区内的刻度 |
| 标注矩形不受绘图区约束 | 「这段下跌」高亮框伸到 x=-165，左边缘留下一道琥珀色竖条 | 给叠加层加 `clipPath`，并把该框在 L(14) 淡出 |
| 成本线/预测线画出绘图区 | 缩放到 slide 视图时水平线从 x=-1681 画起 | 叠加层统一裁剪到绘图区，标签位置钳制 |
| 浮层被镜头推出屏幕 | 镜头移到 `future` 视图后，`sharedX - 430` 让洗盘/出货对照卡跑到 x=-381 | 卡片位置钳制到绘图区内，并在 L(14) 淡出 |
| 筹码叫板超出右边界 | 文本框画到 x=1850（超出 1836） | 左移到 1546，文字居中点同步移到 1691 |
| 组件宽度与 `box.width` 不一致 | `content-box` 下 Tag 的实际宽度比声明宽 38px，连线起点缩在框里 | Tag / PairLabel 加 `box-sizing: border-box` |
| 幕边界整屏闪断 | 切幕那一帧上一幕整体消失，亮度差最高 15.0 | 18 帧交叉淡出，边界亮度差降到 0.2–3.6 |

### 尚未由人眼确认的部分

本环境**没有可用的视觉模型**，`read_image` 对所有已配置模型都返回不支持图像输入。
因此：版面、遮挡、字体重建、节奏感受这些只能由人来看。
程序化 QA 能证明「没有元素越界、没有空帧、没有闪断、字幕始终在场」，
**不能**证明「好看」或「读起来舒服」。请用 Studio 或成片自行确认观感。

字体方面只验证了「有墨迹」（说明不是完全缺字），没有逐一核对字形是否为目标中文字体；
渲染环境是 macOS，`theme.font` 首选 `PingFang SC`，正常情况下可用。

## 7. 复现

```bash
cd remotion

# 重新合成旁白（改台词后必须跑，会重写 narration.timing.json）
npm run narration:build

# 类型 + lint
npm run lint

# 程序化帧 QA
npm run qa:frames

# 预览
npm run dev            # http://localhost:3211

# 出片（headless 为强制要求）
npm run render:market-slang   # → out/market-slang-decoded.mp4
```
