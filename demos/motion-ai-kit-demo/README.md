# Motion AI Kit Demo Explorer

This is a local, dependency-free demo for quickly understanding what Motion AI Kit is for.

Open `index.html` in a browser:

```bash
open demos/motion-ai-kit-demo/index.html
```

What it demonstrates:

- Motion AI Kit is an agent/IDE toolkit, not a frontend component library.
- The kit gives an agent current Motion docs, recommended patterns, and premium example context.
- MotionScore for Agents can classify slow animations and suggest concrete fixes.
- CSS spring generation can turn natural-language animation feel into runtime-free `linear()` easing.
- The transition editor is about visually tuning and saving transitions.

Intentional limits:

- This does not install `npx motion-ai` or connect to Motion+.
- Motion+ features are simulated from the public docs because they require account access.
- The CSS spring curves are representative demo values, not generated by the official MCP in this run.
