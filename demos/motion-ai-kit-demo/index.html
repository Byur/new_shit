AI Kit 是 agent 工具，不是 UI 组件库

它给 Cursor、Codex、Claude Code 等 agent 加上 Motion 专用上下文、命令和 MCP 能力。

它的价值在“建议能落代码”

审计结果会指出具体文件、慢在哪里、怎么改，而不仅是说“动画不好”。

高级能力依赖 Motion+

示例源码、MotionScore、CSS spring 生成和 transition editor 都需要 Motion+ 才能完整使用。
